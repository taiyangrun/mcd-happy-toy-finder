# 玩具图鉴（assets/toys.json）格式与维护说明

本文件是麦当劳开心乐园餐（Happy Meal）玩具的**整理型知识库**，用于本地检索与
玩具档案展示。它不是实时库存数据源，而是「搜集全国各地麦当劳儿童乐园餐玩具」的
收藏图鉴。

## 文件结构
```json
{
  "_meta": { "title": "...", "disclaimer": "...", "schema_version": "1.0", ... },
  "toys": [ { ... }, { ... } ]
}
```

## 单条玩具字段（entry_schema）
| 字段 | 含义 |
|------|------|
| `id` | 唯一标识（建议 `ip-年代` 或 `系列-序号`） |
| `name` | 玩具/系列名称 |
| `series` | 大系列：IP联名 / 自主IP / 节日限定 / 国潮 |
| `ip` | 联名 IP 或自主形象名 |
| `era` | 大致年份或期数 |
| `region` | 发放范围：全国 / 某大区 / 某城市 |
| `rarity` | 稀有度：普通 / 稀有 / 隐藏款 / 限定 |
| `type` | 类型：公仔 / 拼装 / 发声 / 互动 / 贴纸 |
| `description` | 简介 |
| `keywords` | 模糊匹配用的别名/关键词（含中英文） |
| `status` | 当前状态：在售轮换中 / 往期收藏 / 节日限定 |

## 如何扩充
1. 从麦当劳官方 App、开心乐园餐公告、玩家社区收集新一期玩具信息；
2. 按上方 schema 追加一条到 `toys` 数组；
3. `keywords` 尽量覆盖常见叫法（含拼音/英文），提升模糊命中率；
4. **当前正在门店发放的系列，务必把 `status` 设为 `在售轮换中`**，这样当某门店
   `query-meal-detail` 的玩具轮次暴露出该系列名（如「海绵宝宝×航海王系列玩具」）时，
   本 Skill 能直接命中并给出高置信结论；若图鉴里没有对应条目，则只能回退到随机玩具判断。
5. 运行 `python scripts/toy_lookup.py --list` 校验 JSON 格式无误。

## 数据来源声明
当前为「示例种子数据」，覆盖近年常见联名/自主 IP。具体某期玩具是否仍在发放，
以官方实时信息为准。欢迎社区按统一 schema 持续补全，使其更完整、更准确。
